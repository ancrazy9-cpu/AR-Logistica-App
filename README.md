# AR Logística

Sistema móvil de gestión y asignación de transporte de carga.

## Descripción

Aplicación Android desarrollada para facilitar la gestión logística entre clientes, administradores y conductores.

## Módulos

### Cliente
- Registro de solicitudes de transporte.
- Consulta del estado del servicio.

### Administrador
- Gestión de solicitudes.
- Asignación de vehículos y conductores.
- Control de servicios.

### Conductor
- Visualización de servicios asignados.
- Actualización del estado del viaje.

## Tecnologías

- Kotlin
- Android Studio
- XML
- Material Design
